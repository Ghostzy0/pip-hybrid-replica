# Security policy

This is experimental source without a security certification, support SLA, or release binary. Use synthetic content while reviewing it. Do not post access tokens, account screenshots, saved conversations, model weights, private keys or other sensitive material in an issue.

Report suspected vulnerabilities privately through GitHub's repository security reporting feature when it is enabled. Include the affected commit and minimal reproduction. Avoid testing against another person's account, device or data.

Read [privacy boundaries](docs/PRIVACY.md) and [release limits](docs/RELEASE.md) before relying on the app.
