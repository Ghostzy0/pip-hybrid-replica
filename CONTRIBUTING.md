# Contributing

Read the [README](README.md), [parity boundary](docs/PARITY.md), [privacy notes](docs/PRIVACY.md), and [testing guide](docs/TESTING.md) before changing behavior. Keep changes small, use original or explicitly licensed assets, preserve upstream notices, and describe the user-visible behavior and evidence.

For this repository, run only the neutral baseline commands in [EDITIONS](docs/EDITIONS.md). Use synthetic prompts and data. Report source commit, host, exact command and result. Fixture tests and a successful build do not establish completed local/Hybrid parity, provider consent, protected-history acceptance, accessibility, or release readiness.

Preserve local-only fail-closed behavior, visible Stop, explicit review before cloud sending, history recovery, and separate app identity. Never log or commit credentials, private history, model weights, account-bearing captures, build products or runtime caches. Use the issue/PR templates on the repository hosting this checkout. No response schedule or support guarantee is promised.
