# Frequently asked questions

## Is this Perplexity Hybrid Compute?

No. It is an independently authored, partial behavioral experiment that uses selected Perplexity workflows as a reference. It is not affiliated with or endorsed by Perplexity and makes no complete or 1:1 parity claim. See [the evidence-based comparison](PARITY.md).

## What can I do with it?

Use a native Mac workspace for local model chat, verified downloads, visible Stop, encrypted history, and an optional ChatGPT request that you review before sending. It is experimental source, not a complete web-research or agent product.

## Does it implement Hybrid local-to-cloud-to-local tasks?

No completed Hybrid task graph is established. Current source has local chat and a separately reviewed ChatGPT path; routing a task between them, retaining intermediate output and returning to local execution remain a gap.

## Does it bundle the Perplexity model or app assets?

No. Model weights are separate downloads with their own terms. No Perplexity code, marks, screenshots, proprietary app resources, or weights are included.

## Do I need an AI account?

Local use needs no AI account. Optional ChatGPT use requires an eligible account-specific flow and explicit review. Sign-in alone does not guarantee model access. No silent API billing fallback is provided.

## Is the app or local inference security-certified?

No. Read [privacy and network boundaries](PRIVACY.md). The source's local runtime controls and encrypted-history implementation need host-specific runtime qualification. This is not an App Sandbox or network-isolation certification.

## Is there a tested download?

No public binary or release installer is offered by this source snapshot. Local builds are ad-hoc signed and not notarised. See [release limits](RELEASE.md).

## What counts as acceptance?

Source review, fixture tests, screenshots, and compilation answer different questions. Complete local and Hybrid reference tasks, equivalent tests on the exact release build, native error/Stop/restart cases, resource measurements, accessibility review and a pass/partial/fail ledger remain needed for a faithful recreation claim.
