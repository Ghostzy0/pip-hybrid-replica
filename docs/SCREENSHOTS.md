# Screenshot evidence

This repository has no runtime screenshots yet. Do not reuse the custom-edition screenshots as evidence for this neutral replica build.

Add a screenshot only after the exact replica commit has been built and the image reviewed for account, personal, private reference or other sensitive content. Record the source commit, binary identity/hash, host/OS, window size, theme, synthetic-state label and what the image actually shows. Do not infer inference, saved persistence, provider, keyboard, motion or accessibility acceptance from a still image.

Keep raw Perplexity captures private and out of Git. Screenshots are evidence of visible state, not permission to redistribute competitor assets.
